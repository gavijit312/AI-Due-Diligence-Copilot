# 🚀 DueSense AI – Multi-Agent Due Diligence Copilot

> **An enterprise-grade Agentic AI platform that automates legal, financial, and compliance due diligence using LangGraph, RAG, and LLMs.**

## 📌 Overview

DueSense AI leverages **multiple AI agents** to analyze enterprise documents such as contracts, financial statements, compliance reports, and corporate records. It reduces manual review effort by generating risk assessments, executive summaries, and source-backed answers through a Retrieval-Augmented Generation (RAG) pipeline.

## ✨ Key Features

* 🤖 Multi-Agent AI workflow with LangGraph
* 📄 Intelligent document parsing (PDF, DOCX, Excel)
* 🔍 RAG-powered document search and Q&A
* ⚖️ Legal contract analysis
* 💰 Financial statement analysis
* ✅ Compliance verification
* ⚠️ Automated risk assessment
* 📋 Executive summary generation
* 📚 Citation-backed responses to reduce hallucinations

## 🛠️ Tech Stack

* **Languages:** Python
* **AI:** LangChain, LangGraph, OpenAI/Gemini
* **RAG:** FAISS, ChromaDB
* **Backend:** FastAPI
* **Frontend:** Streamlit
* **OCR:** Tesseract
* **Database:** PostgreSQL
